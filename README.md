# Customer_Behavior_Analysis
## 📌 Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, and revenue trends.

## 🛠️ Tools & Technologies
- SQL
- Python
- Pandas
- Power BI
- Excel

## 📊 Project Goals
- Analyze customer purchasing patterns
- Identify top-selling products
- Analyze revenue by different customer groups
- Find useful business insights

## 📁 Project Files
1. `customer_behavior.csv` - Original dataset
2. `customer_behavior.py` - Data cleaning and exploratory data analysis using Python
3. `customer_behavior.sql` - SQL queries and business analysis
4. `customer_behavior.pbix` - Interactive Power BI dashboard

## 🔍 Key Analysis
The project includes:
- Customer segmentation
- Revenue analysis
- Product analysis
- Age-group analysis
- Purchase behavior analysis
